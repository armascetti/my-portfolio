# Mandy Mascetti Portfolio

Professional portfolio website showcasing my software engineering projects, technical skills, and career transition from education to technology.

## About

This portfolio highlights my experience building full-stack web applications, integrating APIs, and developing AI-enhanced solutions. It serves as a central hub for my projects, resume, and professional contact information.

## Features

* Responsive design for desktop and mobile devices
* Featured software engineering projects
* Resume download
* GitHub and LinkedIn links
* Contact information
* Modern user interface

## Technologies Used

* React
* JavaScript
* HTML5
* CSS3

## Featured Projects

### AI Weather Dashboard

A full-stack weather application featuring real-time weather data, forecasting, and AI-generated weather briefings using OpenAI.

### Make Your Marvel

A MERN stack application utilizing the Marvel API to explore characters and related content.

### Spacey

A Django and PostgreSQL application integrating NASA's Astronomy Picture of the Day API.

## Installation

```bash
git clone https://github.com/armascetti/my-portfolio.git
cd my-portfolio
npm install
npm start
```
